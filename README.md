# Aman Gupta — Portfolio

Personal portfolio site for Aman Gupta — Full-Stack Developer & IoT Engineer, B.Tech CSE student at UCER Prayagraj.

**Live:** [amanguptadevportfolio.vercel.app]
(https://amanguptadevportfolio.vercel.app/)

## About

A single-page portfolio showcasing projects, skills, experience, and education — built fully with vanilla HTML/CSS/JS, no frameworks, no build step.

## Sections

- **Hero** — intro with an animated terminal-style code card
- **Projects** — Arohan (autonomous safety rover), EcoBin (IoT waste management), MailExtracto (RPA automation bot)
- **Skills** — Frontend, Backend & APIs, Databases & Platforms, IoT & Hardware
- **About** — bio, education, and background
- **Experience** — timeline of roles, achievements, and education
- **FAQ** — common questions about availability and tech stack
- **Contact** — working contact form (Formspree) + email/social links

## Tech

- Pure HTML/CSS/vanilla JS — single file, no frameworks, no build tools
- Fonts: Playfair Display (serif headings) + Outfit (sans body)
- Custom cursor with hover states (desktop only, mobile-safe)
- Dark/light mode toggle with `localStorage` persistence
- Scroll-triggered reveal animations via `IntersectionObserver`
- Animated terminal widget with typing sequence + progress bar
- Contact form via [Formspree](https://formspree.io), with honeypot spam protection and client-side validation
- Full SEO setup: meta tags, Open Graph, Twitter Card, JSON-LD `Person` schema
- Google Analytics integration
